## 论点逻辑性检查

<!-- 检查文章的内在逻辑：是否存在矛盾、跳跃或谬误 -->

- [ ] CHK001 核心论点在引言段中明确可识别——独立读者可在 10 秒内定位论点句
- [ ] CHK002 引言论点与结论重述一致——表述方式可不同，立场必须相同
- [ ] CHK003 每个论证要点在主体段落中有充分展开——无"列出但未论证"的要点
- [ ] CHK004 论证逻辑链完整——从头到尾通读无断裂或跳跃
- [ ] CHK005 前后断言无自相矛盾——所有主张立场一致
- [ ] CHK006 无"以偏概全"谬误——从个别案例推出普遍结论的论证有约束条件说明
- [ ] CHK007 无"因果倒置"谬误——相关性与因果性明确区分
- [ ] CHK008 无"偷换概念"谬误——关键术语全文定义一致，内涵无中途变更
- [ ] CHK009 无"假两难"谬误——未将复杂问题简化为非此即彼
- [ ] CHK010 无"滑坡谬误"——未在无依据的情况下推断极端后果
- [ ] CHK011 无"诉诸权威"——权威身份未被用作论据的替代品
- [ ] CHK012 每个主体段落聚焦单一论证任务——无跑题或多主题混排
- [ ] CHK013 段落间过渡自然——开头句与上一段结尾句有逻辑衔接
- [ ] CHK014 结论段未引入新论证要点——所有新信息均停留在已论证范围
- [ ] CHK015 目标受众的预设立场/偏见已在文中得到回应——非稻草人版本

## 引用准确性检查

<!-- 检查文章的证据基础：引用是否准确、可追溯、格式统一 -->

- [ ] CHK016 citation-plan.md 中所有"已获取"引用均已在文中实际使用——无遗漏引用素材
- [ ] CHK017 每个论证要点的引用数量 ≥ plan 中定义的下限
- [ ] CHK018 引用多样性——核心论证要点的引用来自不同类型（数据+案例+权威观点，非全部同一类）
- [ ] CHK019 引用时效性——非历史性引用来自近 5 年（或标注历史数据的背景说明）
- [ ] CHK020 引用来源可追溯——URL 可访问 / 文献可检索 / 数据有原始出处
- [ ] CHK021 引用信息准确——抽查的引用中数据、年份、作者名与原文一致
- [ ] CHK022 引用未被断章取义——抽查引用在原文中的上下文与文章摘录意图一致
- [ ] CHK023 引用格式全文统一——学术/大众/社交媒体格式择一使用，全文一致
- [ ] CHK024 每次引用在文内有明确的来源标注——读者可追溯到来源
- [ ] CHK025 未引用不可靠来源——维基百科等开放编辑平台未作为唯一引用（允许作为辅助了解入口）

## 可读性检查

<!-- 检查读者的实际阅读体验：语言、节奏、信息密度 -->

- [ ] CHK026 语言难度匹配目标受众知识水平——专家受众无冗余科普 / 大众受众无未定义术语
- [ ] CHK027 所有专业术语在首次出现时有定义或类比解释
- [ ] CHK028 段落长度分布均衡——无 > 600 字的阅读疲劳段或无 < 100 字的论证不充分段
- [ ] CHK029 相邻段落长度差异不过大——无 150 字段紧接着 800 字段的节奏突变
- [ ] CHK030 平均句长适中——主要段落平均句长 ≤ 40 字（中文可读性标准）
- [ ] CHK031 无 3 层以上嵌套从句的句子——复杂句式已拆分或简化
- [ ] CHK032 被动语态使用率合理——议论文以主动语态为主
- [ ] CHK033 过渡词多样且恰当——未出现 3+ 段连续以相同过渡词开头
- [ ] CHK034 无"注水段"——每个段落去除修饰语后仍有实际论证内容
- [ ] CHK035 无标题党式夸张修辞——标题和引言钩子克制而有信息量
- [ ] CHK036 无"才疏学浅"、"抛砖引玉"等自谦语——以论证品质说话
- [ ] CHK037 以目标受众身份通读全文——未发现晦涩难懂或失去耐心的节点
