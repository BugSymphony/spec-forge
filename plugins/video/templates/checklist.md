## 一、镜头连贯性

- [ ] CHK001 相邻镜头间无跳轴错误——检查所有连续镜头的角色视线方向和运动方向是否一致
- [ ] CHK002 同一场景内动作跨镜头连续——上一个镜头的动作终点与下一个镜头的动作起点可衔接
- [ ] CHK003 场景切换有视觉线索引导——无"凭空出现"的新场景，观众能理解空间关系变化
- [ ] CHK004 景别变化平滑——相邻镜头景别跳跃不超过 2 级（如 LS→MCU 可，LS→CU 不可）
- [ ] CHK005 关键道具在镜头间的位置连续——道具不会突然出现或消失
- [ ] CHK006 角色造型在同一场景内一致——服装、发型、妆容在连续镜头中无变化

## 二、台词自然度

- [ ] CHK007 所有台词已逐句默读，无不自然的书面用语
- [ ] CHK008 无"说教腔"台词——台词不像是向观众讲道理或传达价值观
- [ ] CHK009 无"信息堆砌"台词——每句台词的信息量在自然对话范围内，不需要观众"解码"
- [ ] CHK010 无"信息播报"式台词——角色不是在向观众解释剧情，而是在自然互动
- [ ] CHK011 单句台词不超过 15 个字（短剧节奏要求）
- [ ] CHK012 不同角色的台词有辨识度——遮盖角色名称后能通过语言风格区分说话人
- [ ] CHK013 每句台词有明确的情绪标注和动作提示
- [ ] CHK014 对白与留白比例接近 6:4，信息密度适中

## 三、节奏与时长

- [ ] CHK015 每集时长在目标值 ±5 秒容差内
- [ ] CHK016 每集包含明确的 Hook 段（前 3-5 秒）——前 3 个镜头有效抓住注意力
- [ ] CHK017 每集包含明确的结尾段落（最后 5-10 秒）——有悬念钩子或情感收束
- [ ] CHK018 平均镜头时长在 3-8 秒范围内，无连续极短切镜（< 1 秒 × 3 次）或超长静态画面（> 15 秒）
- [ ] CHK019 全剧情感曲线呈上升趋势——结尾集情感强度为全剧最高或次高
- [ ] CHK020 相邻集情感强度无超过 3 级的跳跃
