## 依赖关系

### Phase 依赖

- **Setup (Phase 1)**: 无依赖，可立即开始
- **Foundational (Phase 2)**: 依赖 Phase 1 完成
- **场次 1 (Phase 3)**: 依赖 Phase 2 完成——按 P1 优先执行
- **场次 2 (Phase 4)**: 依赖 Phase 3 完成——也可在 Phase 3 之后并行启动（若分集无重叠）
- **剩余集数 (Phase 5)**: 依赖 Phase 2 完成——可与 Phase 3/4 并行（若分集无重叠）
- **Polish (Phase 6)**: 依赖 Phase 3-5 全部完成

### 场次间依赖

- 场次目标之间按 Priority 顺序执行（P1 → P2 → P3）
- 同一场次内的各集按集数顺序编写（01 → 02 → N），保证剧情连续性
- 角色和场景一致性依赖 `build/连续性追踪表.md` 跨集同步

- 仅 Phase 3、4 因剧情连续性需要按集数顺序执行
