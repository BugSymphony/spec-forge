## 品质标准

- **QS-001 完整性**：所有 spec、plan 和设计文档的必填字段均已填写，无空占位符。角色设计表覆盖所有出场角色
- **QS-002 一致性**：上下游制品（spec → plan → tasks → dist/）间无矛盾，角色名称、外貌描述、性格设定前后一致
- **QS-003 可执行性**：任务描述具体到可执行的步骤 —— 每格分镜有明确的画面描述和情绪目标
- **QS-004 清晰性**：画风描述有具体参照（如 "类似 XX 作品 XX 章节的画风"或明确参数），避免纯抽象形容词。对白无语病、无歧义
- **QS-005 画面连贯性**：角色设计表在每一话中一致使用，分镜过渡符合视觉规律（遵循 180 度线、运动方向一致、翻页设计合理）
- **QS-006 对白可读性**：对白长度适配画框空间预估，语气符合角色性格描述，无语病。文字不含画面可传达的冗余信息
- **QS-007 叙事节奏**：分镜密度分布合理（高潮页 ≤3 格、过渡页 4-6 格），情绪曲线符合故事类型预期，每话至少含 1 个情绪高点

### 命名规范

- **角色文件**：`角色_[名称]_[序号]_[角度]_v[版本].psd`（如 `角色_优斗_01_正面_v03.psd`）
- **场景文件**：`场景_[名称]_[时间]_[序号].psd`（如 `场景_教室_白天_01.psd`）
- **对白文件**：`对白_[话数]_[页数]_[角色].txt`
- **音效文字**：`SE_[描述]_[话数]_[页数]_[格数].psd`

### 分层规范

每页 PSD 文件的标准图层结构（从上到下）：

1. 对白层（Dialogue）—— 对白气泡 + 文字
2. 音效层（SFX）—— 拟声文字、速度线效果
3. 效果层（Effects）—— 速度线、集中线、网点
4. 上色层（Color）—— 角色 + 背景上色（灰度或彩色）
5. 线稿层（Line）—— 角色 + 背景线稿
6. 草稿/参考层（Sketch）—— 不可见，仅用于绘制参考

### 审查流程

```
线稿审查 → 上色审查 → 对白审查 → 成稿审查
    |            |            |            |
  画稿完成    着色完成     对白排版     全部检查
    |            |            |            |
  Gate: 角色  Gate: 色调  Gate: 对白  Gate: 终审
  一致性检查  一致性检查  清晰性检查  通过/驳回
```

## 治理规则

### 修订流程

1. **提议**：任何创作者可提交修订提案，说明动机和影响范围（受影响的角色/话数/页面）
2. **审查**：主画师评估提议的合理性 —— 特别关注对画面一致性的潜在影响
3. **批准**：审查通过后合并修订
4. **传播**：同步更新所有已产出制品中对宪法的引用。若修订影响已有分镜、角色设计，在 tasks.md 中追加修复任务

### 版本管理

使用 MAJOR.MINOR.PATCH 语义版本：
- **MAJOR**：移除或重新定义核心视觉原则 / 叙事标准
- **MINOR**：新增原则或叙事标准、新增制作规范章节
- **PATCH**：措辞澄清、示例补充、非实质性的格式调整
