## 依赖关系与执行顺序

### 阶段依赖

```
Phase 1 (准备) ──→ Phase 2 (基础资产：角色设计完稿) ──→ Phase 3-6 (第 1 话) ──→ Phase N (第 2 话...) ──→ Phase M (跨话打磨)
                      ↑ BLOCKS 所有话数                          ↑                                   ↑
                                                                  └── 第 1 话完成后方可开始 ──────────→ 所有话完成后方可开始
```

### 并行机会

- Phase 2 的所有角色设计任务（T005-T012）可并行
- 同一话内的不同页面线稿可并行（前提：角色资产已就绪）
- 同一话内的不同页面上色可并行（前提：该页线稿已完成）
- 不同话之间原则上应顺序执行（保证叙事和画风的渐进统一），但可并行准备后续话的角色特殊资产
- Phase M 的所有审查任务可并行

### 执行策略

**MVP（最小可行产出）**：
1. Phase 1-2 完成 → 所有角色资产就绪
2. Phase 3-6 完成 → 第 1 话完整产出
3. **停止并验证**：第 1 话的画风和叙事是否符合 spec 预期？
4. 通过验证后继续第 2 话

**全量交付**：
- 逐话完成 Phase 3-6 的结构
- Phase M 做最终跨话打磨
