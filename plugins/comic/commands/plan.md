# 漫画创作计划制定

## User Input

```text
$ARGUMENTS
```

根据已编写的漫画规格（spec.md）中的故事大纲、画风方向、角色设计目标和叙事单元，制定 **HOW（怎么做/怎么设计）** 层面的创作计划。产出：分镜排列、页面布局、对白时序、以及类型专用的设计文档。

## Pre-Execution Checks

1. 确认 `.specforge/` 存在，当前项目为漫画类型
2. 执行 `specforge list --detail --json` 确认活动 feature
3. 执行 `specforge validate --stage plan --json` 确认前置条件满足
4. 执行 `specforge show --artifact spec` 加载 spec.md 内容
5. 确认 spec.md 中存在故事大纲、画风方向、角色设计目标、叙事单元和内容规模
6. 若 spec.md 不完整 → **ERROR** 提示先执行 `/specforge.specify` 完成规格
7. 执行 `specforge setup plan --json` 初始化 plan 环境（创建 build/ 目录等）

## Outline

### 第 1 步：加载 spec.md 并提取关键设计参数

解析 spec.md 中 plan 阶段需要的输入：

- **故事大纲**：核心情节线，用于确定分镜序列的情感曲线
- **内容规模**：总页数 / 话数 / 每话页数范围 → 用于分配每话页数和分镜密度
- **画风方向**：风格 / 色调 / 线条风格 → 用于生成画风参考板的设计约束
- **角色设计目标**：角色的外貌特征和叙事功能 → 用于生成人物设计稿的参数
- **叙事单元**：每个单元的情绪目标（Given-When-Then 中的 Then 部分）→ 用于确定每个叙事单元对应的分镜序列情绪基调

⚠️ spec.md 中的叙事单元优先级（P1、P2...）决定了分镜设计资源的分配顺序。

### 第 2 步：设计分镜排列（Storyboard Arrangement）

将叙事单元转化为具体分镜序列（HOW 层面）：

**按话拆分**：
- 根据内容规模的每话页数范围，将叙事单元的优先级顺序分配到各话
- 每话的页数 = 总页数 / 话数，确保每话都为整数
- P1 叙事单元优先占用第一话和关键话的页数配额

**每话分镜序列设计**：
- 按页列出该话的分镜序列，格式：

```
第 N 话：[话标题]
├── 第 1 页：[页面类型，如 开场/过渡/高潮/收束]
│   ├── 格 1：[分镜描述，如 "主角站立全景 → 面部特写"]
│   ├── 格 2：[分镜描述]
│   └── 格 N：[分镜描述]
├── 第 2 页：[页面类型]
│   └── ...
...
```

- **分镜描述格式**：`[画面内容/动作] → [构图方式/视角] → [预期情绪效果]`
  - 例如："主角从高处跃下 → 仰视 → 力量感与决心"
  - 例如："反派缓步走出阴影 → 低视角+特写眼部 → 威胁感与压迫"
- 每个分镜描述不超过 15 字，确保简洁可执行
- 分镜之间的过渡类型标记：`切|淡入淡出|画面叠化|平行蒙太奇|...`

**分镜密度规则**：
- 高潮页：≤3 格/页（大画面强调视觉冲击）
- 日常/过渡页：4-6 格/页（标准叙事节奏）
- 快节奏动作页：可尝试 7-8 格（碎片化强化速度感）
- 跨页/大场面：1-2 格/跨页

### 第 3 步：设计页面布局（Page Layout）

定义每页的画框布局方案：

**页面网格系统**：
- 选择基础网格：`3×3`（9 格标准日系）/ `4×3`（12 格灵活） / `2×2`（4 格美漫大画面） / 自定义
- 指定出血（bleed）安全区

**每页布局设计**：
- 使用 ASCII 网格或文字描述每页的格位分布：

```
第 N 话 / 第 X 页
┌─────────┬───┐
│         │   │
│   格1   │格2│
│  (重点) │   │
├────┬────┴───┤
│ 格3│   格4  │
└────┴────────┘
```

- 重点格：标记每页的视觉焦点格（通常面积最大的格），这是读者第一眼会注意的位置
- 视线流：用 `→` 标注读者视线在页面上应走的路线
- 翻页点设计：标记每页最后一格是否为悬念/翻页点（page-turner）

### 第 4 步：设计对白时序（Dialogue Timing）

为每个分镜分配对白或无声标记：

**对白量分配规则**：
- 动作场景：对白 ≤1 句/格（画面优先）
- 对话场景：对白 1-3 句/格（信息传递）
- 内心独白：仅在高情绪格使用（避免过度 exposition）
- 无声格标记为 `[无对白]`，说明该格的静默意图（如 "用沉默表达震惊"）

**对白时序表**：

| 话-页-格 | 角色 | 对白/独白 | 情绪标记 | 备注 |
|-----------|------|----------|---------|------|
| 1-1-1 | [角色A] | [对白内容] | [平静/激动/愤怒/...] | [如 "画面中角色A背对镜头说此句"] |
| 1-1-2 | — | `[无对白]` | 震惊 | 用画面传达情绪，不配文字 |

**对白发声规则**：
- 框外音（offscreen dialogue）：`[OS]` 标记
- 内心独白：`[内心]` 标记
- 旁白/叙述：`[旁白]` 标记
- 群体对话：标注发言顺序

### 第 5 步：生成类型专用设计文档

使用 `specforge setup plan --json` 确认 build/ 目录已初始化，然后生成以下类型专用设计文档：

**文档 1：人物设计稿** → `build/人物设计稿.md`
- 基于 spec.md 中的角色设计目标表，扩展每个角色的视觉设计规格：
  - 正面/侧面/背面三视图的文字描述（或 ASCII 示意）
  - 标志性表情集（≥3 种：常态/愤怒/悲伤/喜悦/惊讶 中选择）
  - 服饰细节（常服 + 关键场景服装）
  - 标志性道具或配件
  - 身高对比图（相对数据）
- 标注角色在分镜中的一致性别名（如"主角 = 优斗"）

**文档 2：分镜草图规划** → `build/分镜草图规划.md`
- 将第 2 步的分镜排列整理为 `[话]-[页]-[格]` 三级索引表
- 每格关联：构图方式（全景/中景/特写/大特写/远景）+ 视角（平视/仰视/俯视/鸟瞰）+ 运动线方向（→/←/↑/↓/↗...）
- 标注需要重绘的高风险格（如复杂透视、多角色同框、大场景）

**文档 3：画风参考板** → `build/画风参考板.md`
- 收集或描述 3-5 幅风格参考（描述现有作品风格或生成 AI 参考 prompt）
- 色调板：定义 5-8 个主色 + 2-3 个辅助色（HEX 或描述色）
- 线条规范：粗细（pt/mm）、笔触类型（G-pen / 丸笔 / 数位板笔刷名）、勾线优先级规则
- 网点/阴影风格：灰度层级（如"4阶灰度：100%/75%/50%/25%"）或排线风格

**通用文档**（保留）：
- `build/research.md` — 风格参考调研、同类作品分析、市场定位
- `build/quickstart.md` — 画师上手指南（工具配置、笔刷设置、文件结构说明）
- `build/contracts/` — 若有协作，定义画师/编剧/填字角色间的交接契约

### 第 6 步：生成 plan.md 主体

将第 2-5 步的设计成果组织为 plan.md 的主体内容：

```markdown
# 创作计划：[漫画标题]

## 摘要
[从 spec 提取故事方向 + 画风方向 + 内容规模 → 概括创作方案]

## 创作上下文
- **内容类型**: 漫画 (comic)
- **画风引擎**: [数码板绘/手绘扫描/混合]
- **目标平台**: [纸媒/Webtoon/电子阅读器/社交媒体]
- **输出格式**: [页漫/条漫]
- **制作规模**: [总页数 / 话数 / 每话页数范围]

## 宪法检查
以宪法中的视觉原则和叙事标准逐一检查创作方案的对齐情况

## 分镜排列
[第 2 步完整输出]

## 页面布局
[第 3 步完整输出]

## 对白时序
[第 4 步完整输出]

## 设计文档清单
- build/人物设计稿.md
- build/分镜草图规划.md
- build/画风参考板.md
- build/research.md
- build/quickstart.md
- build/contracts/
```

### 第 7 步：写入文件

- 将 plan.md 主体写入 `FEATURE_DIR/plan.md`
- 将人物设计稿写入 `FEATURE_DIR/build/人物设计稿.md`
- 将分镜草图规划写入 `FEATURE_DIR/build/分镜草图规划.md`
- 将画风参考板写入 `FEATURE_DIR/build/画风参考板.md`
- 创建或更新 `FEATURE_DIR/build/research.md` 和 `FEATURE_DIR/build/quickstart.md`

## Output

- **主要制品**：`FEATURE_DIR/plan.md`
- **设计文档**：
  - `FEATURE_DIR/build/人物设计稿.md`
  - `FEATURE_DIR/build/分镜草图规划.md`
  - `FEATURE_DIR/build/画风参考板.md`
  - `FEATURE_DIR/build/research.md`

- **格式**：Markdown

## Stage Checkpoints

- [ ] 分镜排列按话-页-格三级索引完整展开
- [ ] 每话页数在内容规模范围内
- [ ] 页面布局含网格系统和视线流指示
- [ ] 对白时序表含所有关键对白和 `[无对白]` 标记
- [ ] 3 个类型专用设计文档（人物设计稿/分镜草图规划/画风参考板）已生成
- [ ] build/ 目录含通用文档（research.md / quickstart.md / contracts/）
- [ ] 宪法检查已逐条对齐
- [ ] **作用域验证**：plan 中不含"为什么要做"的意图层论述（那些是 spec 的内容），全是"怎么做"的结构设计

## 质量门禁

- 分镜排列是否具体到每个格都有画面描述和情绪效果？
- 页面布局的视线流是否有明确方向（避免读者困惑）？
- 对白时序中的 `[无对白]` 格是否有明确的静默意图说明？
- 画风参考板是否包含具体参数（颜色值/线条粗细/灰度层级），而非仅"好看的感觉"？
- 人物设计稿是否覆盖正面/侧面/背面三视图 + 表情集 + 服饰 + 道具？

**下一步**：执行 `/specforge.tasks` 将创作计划拆分为可执行任务
