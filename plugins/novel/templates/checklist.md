## 2. 人物一致性

### 2.1 行为一致性

- [ ] CHK017 角色行为符合其性格设定（无"为剧情服务"式强行行为）
- [ ] CHK018 角色重大决定有充分的动机支撑和合理的心理铺垫
- [ ] CHK019 角色成长/变化呈阶梯式递进（非"一夜转变"）
- [ ] CHK020 同一角色在不同章节中展示了性格的多面性（非单一脸谱）

### 2.2 语言一致性

- [ ] CHK021 同一角色的对话风格在全书保持一致（口癖、惯用语、称呼方式）
- [ ] CHK022 角色语言复杂度与身份匹配（贵族→正式、市井→俚语、学者→学术）
- [ ] CHK023 不同角色的对话各有特色，读者可通过对话区分角色身份
- [ ] CHK024 无"信息搬运式"对话（角色为解释信息给读者听而说的不自然对白）

### 2.3 关系一致性

- [ ] CHK025 角色关系的演变有递进层次（相识→了解→信任→亲密）
- [ ] CHK026 敌对关系转变有关键触发事件（非"突然和好"或"突然翻脸"）
- [ ] CHK027 关系变化有足够的篇幅来表现（非"一笔带过"式转变）
- [ ] CHK028 三角/多角关系中的情感逻辑自洽

### 2.4 角色完整性

- [ ] CHK029 所有在规格中定义的主要角色均已出场/将在已规划的章节中出场
- [ ] CHK030 无"工具人"角色（仅为推动剧情出现，无独立人格和动机）
- [ ] CHK031 每个主要角色在故事中做出了至少 1 个主动选择（非完全被动）

## 3. 语言与叙事质量

### 3.1 语言规范

- [ ] CHK032 无连续使用相似句式（如连续3句以上"他...了"结构）
- [ ] CHK033 同段落内无明显词汇重复（无"水字数"嫌疑）
- [ ] CHK034 动作场景使用短句控制节奏（平均 <20字/句）
- [ ] CHK035 情感和内心独白场景有足够的延展（非"草草带过"）
- [ ] CHK036 无错别字和基础语法错误

### 3.2 描写质量

- [ ] CHK037 场景描写充分调动感官（视觉 + 至少1种其他感官）
- [ ] CHK038 每1000字至少有1处非视觉感官描写
- [ ] CHK039 环境描写服务于氛围营造（非"为描写而描写"）
- [ ] CHK040 人物外貌/动作描写与性格一致，非冗余堆砌

### 3.3 信息传递

- [ ] CHK041 世界观信息融入叙事（"展示而非说教"）
- [ ] CHK042 无大段说明性文字（>300字的纯世界观/背景解释）
- [ ] CHK043 每章有至少 1 个核心信息增量
- [ ] CHK044 新的设定信息在需要时才揭示（非"开头全部交代"）

### 3.4 读者体验

- [ ] CHK045 第1章前 200 字建立了足够的好奇心或情感连接
- [ ] CHK046 每章结尾有悬念钩子或情感余韵
- [ ] CHK047 场景转换流畅无磕绊感
- [ ] CHK048 时间跳跃有适当标记（如"三个月后"、"翌日清晨"）
